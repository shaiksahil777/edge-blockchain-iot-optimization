# Edge-Assisted Blockchain-Enabled Secure IoT Communication

A simulation-based research project exploring secure and efficient IoT communication using **Edge Computing, Blockchain, PSO, and WOA**.

## Overview

The project integrates Particle Swarm Optimization (PSO) and Whale Optimization Algorithm (WOA) to optimize selected blockchain and edge-resource parameters, including:

- Block size
- Validation timeout
- CPU
- Memory
- Bandwidth

The system is evaluated against a fixed baseline using latency, energy, throughput, consensus time, scalability, and security metrics.

## Technologies

- Python
- IoT
- Edge Computing
- Blockchain
- PSO
- WOA
- Data Analysis

## Results

The completed simulation showed improved measured latency, energy efficiency, and throughput for the optimized configurations compared with the fixed baseline.

Security validation achieved **100% detection** of the synthetic malicious transactions tested, with no malicious transactions accepted.

## Experiments

- Baseline vs PSO vs WOA
- 5-run performance evaluation
- Scalability testing: 5–50 IoT devices
- Security robustness: 10–40% malicious traffic
- PSO and WOA convergence analysis
